Радиус фрезы по фото

Всё считается прямо в браузере, без сервера. Для масштаба нужен ArUco-маркер известного размера в кадре рядом с фрезой.

Как снимать

  1. Распечатай ArUco-маркер (словарь ARUCO_MIP_36h12, id 0) — генератор здесь. Замерь длину его стороны линейкой в мм.
  2. Положи маркер в одной плоскости с торцом фрезы, camera строго перпендикулярно (не под углом).
  3. Сфотографируй так, чтобы маркер и режущая кромка попали в кадр целиком.

1. Фото и калибровка

Загрузи фото — маркер определится автоматически.

2. Измерение

Вручную: кликни в центр торца фрезы, затем на край режущей кромки — это и есть радиус.

Библиотеки

js-aruco2 — детекция ArUco-маркера для определения масштаба px→мм (полностью в браузере).
OpenCV.js — Hough-детекция окружностей для автоматического поиска кромки фрезы.
Обе загружаются с CDN, сервер не нужен — страницу можно просто закинуть на GitHub Pages.
